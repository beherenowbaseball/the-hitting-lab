# The Drill Lab — Design Direction

## Reference
The Players Tribune + Sports Illustrated editorial aesthetic. Clean, premium, authoritative. Feels like a feature story, not a coaching website.

## Chosen Approach: "Sports Editorial"

**Theme Name:** The Long Read
**Design Movement:** Premium sports editorial — The Players Tribune meets The Atlantic meets Sports Illustrated
**Core Principles:**
1. Content is the hero. Typography and whitespace do the heavy lifting — not decoration.
2. Photography is cinematic and full-bleed. Images are editorial, not stock.
3. Every section earns its place. Nothing decorative that doesn't serve the story.
4. The page reads like a feature article, not a landing page.

**Color Philosophy:**
- Background: Pure white `#FFFFFF` and off-white `#F7F6F4` (warm paper tone)
- Foreground: Near-black `#111111` (not pure black — softer, more editorial)
- Accent: Deep red `#C41E3A` — the SI red, used sparingly for drill numbers, labels, and CTAs
- Muted: `#6B6B6B` for secondary text, timestamps, metadata
- No gradients except the hero image overlay (black to transparent)

**Layout Paradigm:**
- Full-bleed hero image with text overlay — like a magazine cover
- Below hero: clean white sections with generous padding
- Drill cards: editorial article-card style — photo top, text bottom, no borders, subtle shadow
- Asymmetric pull quotes and callout sections break the grid intentionally

**Signature Elements:**
1. Serif italic headlines (Playfair Display) — the editorial voice
2. Tight uppercase sans-serif labels in accent red (drill numbers, section headers)
3. Full-bleed photography with dark gradient overlays for text legibility

**Typography System:**
- Display/Headlines: Playfair Display — italic for emotional impact, bold for authority
- Body/UI: Inter — clean, readable, modern
- Labels/Caps: Inter with `letter-spacing: 0.1em` in uppercase

**Brand Essence:** The Drill Lab — the most serious hitting program you've never heard of, built for players who are tired of thinking and ready to feel.
**Personality:** Authoritative. Honest. Unconventional.

**Brand Voice:** Direct, confident, never salesy. Sounds like a coach talking to a parent after practice, not a marketer.
- Example headline: "Overthinking mechanics is an epidemic."
- Example CTA: "Ready to work together? Here's how."

**Signature Brand Color:** Deep red `#C41E3A`

## Style Decisions
- No rounded corners on cards — sharp edges feel more editorial and serious
- No box shadows on hero — let the image breathe
- Drill cards use 4:3 aspect ratio images, like magazine photo crops
- Pull quote section uses warm off-white background to break the white monotony
- Nav is minimal: wordmark left, 3 links right, no hamburger on desktop
- Mobile nav collapses to just the wordmark + a clean menu icon
